# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project!

We welcome all contributions, including bug reports, bug fixes, documentation improvements, enhancements, suggestions, and new ideas.

## How to Contribute

1. Fork this repository to your GitHub account.
2. Clone your fork to your local development environment.
3. Create a new branch for your proposed changes.
4. Make your changes and test them.
5. Commit your changes with a clear, descriptive message.
6. Push your changes to your fork.
7. Submit a pull request explaining your contribution.

## Reporting Bugs

If you identify an error or unexpected behaviour, please open a GitHub Issue describing the problem and how it can be reproduced.

## Suggesting Enhancements

Suggestions for improving the calculator's functionality, accessibility, usability, and documentation are welcome.

## Code Quality

Please ensure that contributions are clearly documented, tested where appropriate, and consistent with the project's purpose.

## Code of Conduct

All contributors are expected to follow the guidelines in CODE_OF_CONDUCT.md.
