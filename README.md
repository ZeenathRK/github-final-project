# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Project Description

This project provides a simple interest calculator for individuals who want to understand the interest earned or charged on a principal amount. It is developed as part of an open-source initiative supporting financial literacy and accessibility.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal (P):** Initial amount of money
- **Rate (R):** Annual interest rate in percentage
- **Time (T):** Time period in years

## How to Run

Run the Bash script using:

`bash simple-interest.sh`

Enter the principal amount, annual interest rate, and time period when prompted.
